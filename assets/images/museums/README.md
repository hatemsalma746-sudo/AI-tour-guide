# Museum photos

The location screen uses these local photos:

- `egyptian_museum_tahrir.jpg` — [Egyptian Museum in Cairo](https://www.pexels.com/photo/old-palace-with-bas-reliefs-and-arched-entrance-on-well-groomed-square-4353815/), photographed by Spencer Davis; provided under the Pexels license.
- `grand_egyptian_museum.jpg` — [Grand Egyptian Museum facade](https://www.pexels.com/photo/facade-of-the-grand-egyptian-museum-in-giza-egypt-26964135/), photographed by Omar Elsharawy; provided under the Pexels license.

Both images are included as local app assets and displayed with `BoxFit.cover` in the responsive museum card. Keep this attribution with the image files.
